# PathAble

## Try it live

**https://manimimohit-glitch.github.io/pathable/**

Voice-first indoor navigation with real-time obstacle detection for blind and
visually impaired users. Runs entirely in the browser on the device — nothing
to install, no account, nothing uploaded.

The camera requires an HTTPS address, so open the link above rather than a local
copy. On a phone, use your browser's **Add to Home Screen** for an app icon.

See the [README](README.md) for features, architecture, and how to run it
locally.
